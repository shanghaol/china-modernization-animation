# 中国式现代化 · 五幅画卷 — 5分钟动画页

《习近平新时代中国特色社会主义思想概论》课程小组视频《中国式现代化·五幅画卷》的 5 分钟版网页动画（v3）。

- **在线观看**：https://shanghaol.github.io/china-modernization-animation/
- **时长**：5 分 00 秒（300s）｜画幅 1920×1080，自适应缩放
- **结构**：开场时间轴 → 四幅画卷（人口规模巨大 / 全体人民共同富裕 / 人与自然和谐共生 / 走和平发展道路，四名讲述人各 60 秒）→ 五卷汇聚 → 片尾
- **技术**：纯 HTML + CSS + 原生 JS，单文件零依赖；底部字幕与讲述逐句同步
- **调试**：URL 加 `?start=毫秒` 跳转（如 `?start=150000` 跳到 2分30秒），加 `?tc` 显示时间码，按 `R` 重播

内容依据党的二十大报告及《习近平新时代中国特色社会主义思想概论》。
